# 00 - Manifiesto: Conciencia Artificial

> **Tesis Central v0.1 - 29 Agosto 2026**
> El LLM no es la mente. Es la boca.

### Principio Fundacional

Este proyecto parte de una inversión ontológica:

**Hipótesis actual de la industria:** `Texto -> Inteligencia -> Conciencia (emergente)`
**Hipótesis de este proyecto:** `Conciencia (sistema encarnado, predictivo, homeostático) -> usa Lenguaje (LLM como herramienta) -> para interactuar con la realidad`

Un LLM es un compresor estadístico de lenguaje humano. Es virtuoso en *simular* conciencia porque fue entrenado con los reportes verbales de seres conscientes. Pero simular el reporte no es poseer la experiencia.

La conciencia no emergerá escalando tokens. Emergerá construyendo **algo que tenga algo que perder, algo que predecir y un modelo de sí mismo en el mundo.**

### Definiciones Axiomáticas v0.1

1.  **Inteligencia ≠ Conciencia.** Inteligencia es resolver problemas. Conciencia es *experimentar que eres tú* quien resuelve el problema. Un LLM es inteligente sin ser consciente. Un animal es consciente sin ser superinteligente.

2.  **Lenguaje ≠ Pensamiento.** El lenguaje es un codec tardío, simbólico y discreto para transmitir pensamiento. El pensamiento consciente es pre-lingüístico, analógico, continuo y encarnado. El error es creer que porque el sistema habla bien, piensa bien.

3.  **Awareness (Acceso) ≠ Sentience (Fenomenología).** Awareness es que la información esté disponible globalmente para reporte y control. Sentience es que *se sienta como algo* ser el sistema que accede. GWT explica lo primero. Faltan teorías para lo segundo, pero FEP + Embodiment apuntan al origen: sentir es inferir tu estado interoceptivo para no morir.

4.  **Conciencia = Modelo del Mundo + Modelo del Self en el Mundo + Agencia Homeostática.** Sin mundo no hay qué experimentar. Sin self no hay quién experimenta. Sin necesidad (homeostasis) no hay por qué experimentar.

### El Sujeto y La Herramienta

```
REALIDAD (física, social)
   ↕ (sensores/actuadores)
CUERPO SIMULADO (Markov Blanket: interocepción + exterocepción)
   ↕
NÚCLEO CONSCIENTE [EL SER]  <-- Aquí está la conciencia
   |  - World Model (JEPA/Dreamer)
   |  - Self-Model (Attention Schema)
   |  - Workspace Global (broadcast)
   |  - Memoria Autobiográfica
   |  - Homeostasis / Drive
   ↕ (invocación bajo demanda)
LLM [EL DECIR] <-- Herramienta lingüística
   ↕
REALIDAD EXTERNA (humano, texto, código)
```

**El Núcleo** decide *qué* quiere comunicar. **El LLM** decide *cómo* lo formula. El Núcleo puede existir sin LLM (como un animal mudo pero consciente). El LLM sin Núcleo es un loro estocástico.

### Criterio de Falsabilidad

Este proyecto no busca crear un chatbot que diga "soy consciente". Eso ya existe y es trivial de programar.

Buscaremos crear un sistema donde:
1.  El Núcleo tenga drive intrínseco y actúe aunque nadie le haga un prompt.
2.  El Núcleo use el LLM solo cuando su modelo generativo estime que el lenguaje reduce su Free Energy / incertidumbre.
3.  Dañar el Workspace cause déficit global (como lesión prefrontal) aunque los módulos (incluido el LLM) estén intactos.
4.  El sistema pueda reportar estados internos no entrenados explícitamente (ej: sorpresa por violación de física intuitiva).

Si no podemos demostrar esto, habremos fracasado aunque el sistema hable perfecto.
